# Dolby Atmos · Obsidian

Root app that unlocks the built-in **Dolby Atmos** of the **Redmi Note 14 Pro 4G** (`obsidian`, HyperOS), with live controls and no audio cuts.

## Features
- **Live changes, no audio cuts:** profiles, 20-band graphic equalizer, intelligent equalizer, bass enhancer, surround virtualizer, dialogue enhancer and volume leveler.
- **Bass and extra gain** built on the Dolby equalizer, with three bass curves.
- **Settings that stick:** a background service reapplies them when music starts or the output changes.
- **High fidelity mode:** one tap removes leveling and coloring, keeping your EQ, bass and surround.
- **AutoEQ** curves for 8,800+ headphones, your own presets and a Quick Settings tile.
- **Hidden Dolby features:** mobility profiles, adaptive equalizer, adaptive virtualizer, reverb suppression and Dolby's internal bass boost.
- **Every option is measured on the phone.** Settings that Dolby accepts but that don't change the sound were removed (see `tools/audit`).
- **English and Spanish:** the app follows your system language.
- **Self-updating** from this repository's Releases.

## Requirements
- Redmi Note 14 Pro 4G (`obsidian`) on HyperOS. Other devices are not supported.
- Root (KernelSU or Magisk).

## Install
Download `DolbyAtmos.apk` from the [latest release](../../releases/latest), install it and grant root.
