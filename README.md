# Dolby Atmos · Obsidian

Control del Dolby Atmos nativo del **Redmi Note 14 Pro 4G** (`obsidian`, HyperOS) con root.

- Cambios en vivo, sin cortar la música: perfiles, ecualizador de 20 bandas, ecualizador inteligente, graves, envolvente, diálogos y nivelador.
- AutoEQ para más de 8800 auriculares, presets propios y botón en los ajustes rápidos.
- Funciones ocultas de Dolby: perfiles de movilidad, funciones inteligentes, supresión de reverberación y virtualizador de auriculares.
- Se actualiza sola desde las Releases de este repositorio.

**Requisitos:** root (KernelSU o Magisk). Pensada solo para este modelo.

**Instalar:** descarga `DolbyAtmos.apk` de la última [Release](../../releases/latest) y concédele root.

Créditos: control del efecto basado en el trabajo de Paranoid Android y Lunaris AOSP (Apache-2.0); curvas de [AutoEq](https://github.com/jaakkopasanen/AutoEq).
